🔔 การแจ้งเตือน

เปิดการแจ้งเตือนบนเบราว์เซอร์/มือถือ
ยังไม่ได้อนุญาต

🔗 คำสำคัญจับคู่สถานะจาก Skynet
เมื่อวางข้อความจาก Skynet ระบบจะค้นคำเหล่านี้ (คั่นด้วยจุลภาค) รอบ ๆ เลข Skynet Ref. ของแต่ละ Case เพื่อเดาว่าควรอัปเดตเป็นสถานะไหน — ปรับคำให้ตรงกับข้อความจริงที่ Skynet แสดงได้เลย
🔐 ตั้งค่า PIN สำหรับแก้ไขข้อมูล
PIN ใช้ป้องกันไม่ให้คนอื่นแก้ไขหรือลบข้อมูลโดยไม่ได้รับอนุญาต (ค่าเริ่มต้น: 1234)
🔗 การเชื่อมต่อ Microsoft 365
ระบบเก็บข้อมูลใน SharePoint List ของทีมคุณ ทุกคน sign in ด้วยบัญชี Microsoft 365 ของตัวเอง — ไม่มี real-time push แบบ Firebase (ข้อจำกัดของเว็บไซต์แบบ static) แต่จะรีเฟรชอัตโนมัติเป็นระยะ + กดรีเฟรชเองได้ตลอด และรู้ว่าใครแก้ไขล่าสุดจริง ๆ (SharePoint บันทึกให้อัตโนมัติ)
ใส่ Tenant ID แทนได้ถ้าอยากจำกัดให้ล็อกอินได้เฉพาะองค์กรคุณ

ทำ 2 ส่วนนี้ครั้งเดียว (คุณทำเองได้ ไม่ต้องพึ่ง IT):
1
สร้าง SharePoint List ชื่อ "FDA Cases" (หรือชื่อที่ต้องการ) แล้วสร้างคอลัมน์ตามนี้ — Title ใช้เป็นรหัส Case, ที่เหลือเป็น "Single line of text" ทั้งหมดยกเว้นที่ระบุ:
Product Supplier Stage (Number) SubmitDate (Date) Deadline (Date) Officer SkynetRef Note (Multiple lines) DeviceClass (Number) Pathway EtaDate (Date) EtaMin (Date) EtaMax (Date)
2
สร้าง App registration ใน Azure Portal (entra.microsoft.com → App registrations → New registration):
  • Supported account types: เลือก "Accounts in this organizational directory only" (หรือกว้างกว่าถ้าต้องการ)
  • Redirect URI: เลือกแบบ Single-page application (SPA) ใส่ URL ของเว็บนี้ที่ deploy จริง เช่น https://your-username.github.io/your-repo/
  • ไปที่ API permissions → Add permission → Microsoft Graph → Delegated → เพิ่ม: Sites.ReadWrite.All User.Read
  • ถ้า Sites.ReadWrite.All ต้องขอ Admin consent — กดปุ่ม "Grant admin consent" (ถ้าคุณเป็น admin เองก็กดได้เลย)
  • คัดลอก "Application (client) ID" จากหน้า Overview มาใส่ในช่องด้านบน
